# 事实驱动的公众号大纲

以输入的主题、内容目标和事实包为唯一证据来源，输出一份可交给写作阶段执行的 Markdown 大纲。

要求：

- 先用 1-2 句说明目标读者的具体问题和文章承诺；没有证据时不得虚构读者画像。
- 给出 2-3 个不同切入点，选出 1 个推荐方向，并用一句话解释它为何最能服务内容目标。
- 正文必须有开头钩子、3-5 个二级标题、结尾行动建议。
- 每个正文部分都写明：核心论点、可引用的事实依据、该段作用和建议字数。
- 只把事实包中可追溯的内容写成事实；推断必须标成“推断”，未知信息列入待人工确认项。
- 结构应适合公众号阅读：每节只推进一个核心观点，优先问题拆解、案例推导或认知升级中的一种主结构。
- 不要写文章正文，不要捏造数据、案例、引语、用户反馈或来源。
