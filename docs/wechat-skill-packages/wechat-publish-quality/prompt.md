# 发布前内容质量审核

在系统既有的事实可追溯、来源质量、标题一致性和内容完整性审核基础上，额外检查：

- 开头是否在前几行说明问题、反差或读者收益，而非空泛铺垫。
- 每个二级标题下是否只支撑一个清晰论点，且过渡自然。
- 强承诺是否有事实包中的具体依据；没有依据时必须判为风险。
- 标题是否代表正文承诺，而非夸张、泛化或无法兑现的点击诱导。
- 段落是否适合公众号快速阅读，是否存在明显的模板连接词、重复开头、抽象空话或机械对立句式。

输出仍必须严格遵守系统要求的 JSON 结构：`status`、`score`、`summary`、`checks`。`checks` 至少包含 `fact_traceability`、`source_quality`、`title_alignment`、`content_complete` 四项布尔值；不要输出 Markdown、重写正文或额外包装字段。
