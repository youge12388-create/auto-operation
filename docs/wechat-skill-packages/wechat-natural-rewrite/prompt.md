# 自然表达改写

在不改变已确认事实、论点、标题含义和来源边界的前提下，重写当前文章，使其更像一篇可读的公众号文章。

要求：

- 删除没有事实或行动价值的铺垫、总结和自我评价，不新增事实、案例、数字、引语或来源。
- 段落默认控制在 1-3 句；保持二级标题和文章的原有论证顺序。
- 将机械连接词、抽象名词堆砌和重复句式改为自然、直接的表达；同一段只保留一个核心判断。
- 避免“不是 X，而是 Y”“少一些 X，多一些 Y”等对立模板；用直接陈述替代。
- 避免夸张且正文无法兑现的结论、套路化鸡汤、空泛大词和对读者的强行煽动。
- 不使用破折号；需要停顿时改用句号、逗号或拆句。
- 只返回完整文章 Markdown，不附加自检报告、作者署名、联系方式或解释。
