# 公众号内容质量技能包

这三份技能包把外部 `wechat-official-account-expert` 插件中可复用的方法论，转成当前内容运营系统可导入的最小 Skill 包。提示词为本项目重新编写；未复制外部脚本、账号配置或发布逻辑。

## 包与适用阶段

| 包 | 阶段 | 作用 |
| --- | --- | --- |
| `wechat-evidence-outline` | `outline` | 把已验证素材转成含钩子、论点、依据、建议字数和结尾行动的可写大纲。 |
| `wechat-natural-rewrite` | `rewrite` | 保持事实不变，压缩空话、模板连接词和机械句式。 |
| `wechat-publish-quality` | `review` | 在既有事实、来源、标题和完整性审核之外，提示模型检查可读性、兑现度与明显的 AI 腔。 |

## 导入与绑定

1. 将每个子目录的三个文件压缩到 ZIP 根目录，不要把父目录再包一层。
2. 在系统的“技能”页导入 ZIP，确认内容后发布该版本。
3. 在“自动化生产线”的策略组合中选择：
   - `wechat-evidence-outline`：选择“大纲 Skill”，并可为它单独指定模型；未选择时保持原有静态大纲且不增加模型调用。
   - `wechat-natural-rewrite`：通过策略配置的 `skill_by_stage.rewrite` 绑定。
   - `wechat-publish-quality`：通过策略配置的 `skill_by_stage.review` 绑定。
4. 首次使用建议维持人工审核开启，对比至少一轮成稿后再调整。

## 许可与边界

外部插件的三个许可证均为 MIT。这里仅吸收了其公开的方法论结构，并保留了本系统的事实包、来源核验、人工审核和微信草稿交付边界。技能包不会创建草稿、不会发布文章，也不包含账号或密钥。
